## 一句话定义

**共享 Apple ID = 一个账号被多个使用者轮流登录，用于在 App Store 下载该账号已经购买过的应用。**

它共享的是「购买记录」，不是个人数据。你在商店里下载完就退出，账号里的照片、通讯录、备忘录跟你没有任何关系——前提是你**只登 App Store，不登 iCloud**。

## ⚠️ 三条铁律（不遵守会锁机）

> 每年都有人因为跳过这三条把 iPhone 变成砖头，然后回来问怎么办。

**① 只在 App Store 登录**

打开 App Store → 点右上角头像 → 拉到最底部 → 退出登录 → 输入共享账号。
**绝对不要**在「设置」里最顶部那个 Apple ID 位置登录，也不要登录 iCloud。

**② 看到「升级账户安全」一律选「不升级」**

首次登录会弹「Apple ID 安全：是否升级账户安全」，选「**其他选项**」→「**不升级**」。
共享号一旦开了双重认证，其他所有使用者都会被你锁在门外。

**③ 下载完立刻退出**

用完不退 = 占用账号 + 同时在线设备过多 → 触发 Apple 风控 → 账号被锁。
绝大多数「账号已被锁定」都是上一个人没退造成的。

## 能做什么 / 不能做什么

| 可以做 | 不可以做 |
|---|---|
| 在 App Store 下载已购应用（小火箭、Quantumult X、Stash 等） | 登录 iCloud / 设置里的 Apple ID |
| 接收应用更新（在账号仍可用期间） | 绑定自己的手机号或开启双重认证 |
| 下载完退出，回到自己的账号 | 绑定支付方式、充值、内购 |
| | 修改密码、修改密保问题 |
| | 转借他人或长期挂着不退 |

**判断标准很简单**：任何会让你「拥有」这个账号的操作，都不行。共享号你只有临时使用权。

## 常见问题

**Q：共享 ID 会泄露我的隐私吗？**
不会，只要你不登 iCloud。App Store 登录只做一件事：验证「这个账号买过这个应用」。商店看不到你的照片、通讯录、定位。

**Q：提示「Apple ID 已被锁定」怎么办？**
这个使用者侧无法自救，只能换一个账号。锁定的原因是并发登录过多或有人没退出。

**Q：提示「密码错误」？**
九成是密码已经被轮换了，你用的是旧密码。回取号页重新拿一次。

**Q：下载的应用会随账号退出而消失吗？**
不会。应用已经装在本机，退出账号不影响使用。但**更新时需要重新登录该账号**——这是共享号的天然缺陷，也是很多人最终转独享号的原因。

**Q：能不能用共享号买付费应用？**
不能。绑定支付方式会立即触发风控，账号当场失效。
